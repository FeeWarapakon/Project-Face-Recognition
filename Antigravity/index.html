Camera Input

MTCNN Detection

ทำงานผ่าน 3 โครงข่ายย่อย (P-Net → R-Net → O-Net) ตรวจจับตำแหน่งใบหน้า ค้นหา 5 Facial Landmarks และทำการ Crop & Align เป็น 112x112

STAGE 03 Feature Extractor

MobileFaceNet

โครงข่าย Lightweight CNN สกัดเอกลักษณ์ใบหน้าออกเป็น Face Embedding Vector มิติสูง พร้อมทำ L2-Normalization (Unit Vector)

SQLite Vector Match

ทำไมต้องผ่าน MTCNN ก่อนส่งเข้า MobileFaceNet?

ในระบบรู้จำใบหน้าที่แม่นยำ การส่งภาพดิบจากกล้องเข้าสู่โมเดลสกัดเวกเตอร์โดยตรงมักทำให้ความแม่นยำตกต่ำอย่างมาก เนื่องจากขนาดใบหน้า องศาการเอียง และตำแหน่งในภาพไม่คงที่ MTCNN (Multi-task Cascaded Convolutional Networks) จึงทำหน้าที่สำคัญ 2 ประการ:

1

Proposal Network (P-Net)

โครงข่าย Fully Convolutional ทำการสแกนภาพ Image Pyramid ทุกขนาดอย่างรวดเร็ว เพื่อสร้าง Candidate Bounding Boxes นับร้อยจุดที่มีโอกาสเป็นใบหน้า

2

Refine Network (R-Net)

รับภาพขนาด $24 \times 24$ จาก P-Net เพื่อกรอง False Positives (วัตถุที่ไม่ใช่ใบหน้า) ออกไป พร้อมทำ Non-Maximum Suppression (NMS) และปรับพิกัดกรอบให้ชิดขึ้น

3

Output Network (O-Net) & 5 Landmarks Alignment

โครงข่ายที่ซับซ้อนที่สุด รับภาพ $48 \times 48$ ระบุ Bounding Box ขั้นสุดท้าย พร้อมตรวจจับพิกัด 5 จุดสำคัญบนใบหน้า (ตาซ้าย, ตาขวา, จมูก, มุมปากซ้าย, มุมปากขวา) เพื่อทำ Face Alignment ปรับให้ใบหน้าตั้งตรงเสมอ

การระบุตัวตนด้วย Cosine Similarity

เมื่อผ่าน MobileFaceNet เวกเตอร์ใบหน้าจะกลายเป็นพิกัดในมิติสูง (High-dimensional Space) การเปรียบเทียบจะไม่วัดด้วยระยะห่างทางกายภาพ (Euclidean Distance) เพียงอย่างเดียว แต่วัด มุมองศา (θ) ระหว่างทิศทางของเวกเตอร์

สูตรการคำนวณ Cosine Similarity (และ $L_2\text{-Normalized}$ Dot Product)
\text{Cosine Similarity} = \cos(\theta) = \frac{\mathbf{A} \cdot \mathbf{B}}{\|\mathbf{A}\|_2 \|\mathbf{B}\|_2} = \mathbf{A} \cdot \mathbf{B}
*เนื่องจากเวกเตอร์ผ่าน $L_2\text{-Normalization}$ ทำให้ $\|\mathbf{A}\|_2 = 1$ และ $\|\mathbf{B}\|_2 = 1$ จึงคำนวณด้วย Dot Product ได้รวดเร็วระดับ Microseconds
ค่าคะแนนใกล้ 1.0 (มุมเล็ก)

เวกเตอร์ชี้ไปในทิศทางเดียวกัน แปลว่าใบหน้าเป็นของบุคคลเดียวกันอย่างแน่นอน

ค่าคะแนนต่ำกว่า 0.60 (มุมกว้าง)

เวกเตอร์ชี้ไปคนละทิศทาง ระบบจะตัดสินใจเป็น Unknown ทันที
