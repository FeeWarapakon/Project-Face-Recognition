Evidence & Audit

4 หลักฐานยืนยันว่าโปรเจกต์นี้ยังเป็นโมเดลธรรมดา (FP32)

1. ขนาดไฟล์โมเดล (`13,982,183 bytes`)

ไฟล์ models/mobilefacenet.onnx มีขนาด 13.98 MB ซึ่งเป็นขนาดมาตรฐานของสถาปัตยกรรม ArcFace-MobileFaceNet ที่เก็บค่าน้ำหนักเป็น Float32 (4 Bytes ต่อ Weight) หากผ่านการ Quantize INT8 ขนาดไฟล์จะต้องลดลงเหลือประมาณ ~3.5 MB

2. ชนิดข้อมูลในโค้ด `main.py`

ในฟังก์ชัน preprocess_face() (บรรทัดที่ 68–70) มีการแปลงภาพเป็น np.float32 ชัดเจน และไม่มีการแปลงช่วงข้อมูลเข้าสู่ Integer:

face_normalized = (face_rgb.astype(np.float32) - 127.5) / 128.0
return np.expand_dims(..., axis=0).astype(np.float32)
3. แหล่งที่มาใน `README.md`

ในไฟล์ README.md ระบุคำสั่งดาวน์โหลดโมเดลต้นทาง:

wget https://github.com/onnx/models/.../arcface_w600k_mbf.onnx

ซึ่งเป็นไฟล์ Official Pretrained FP32 จาก ONNX Model Zoo โดยตรง

4. ไม่มีไลบรารี Quantization ในโค้ด

ในโปรเจกต์ไม่มีการนำเข้า onnxruntime.quantization, ไม่มีการทำ Static Calibration และไม่มีไฟล์โมเดล quantized เช่น .int8.onnx หรือ _quant.onnx

Code Review Findings

จุดที่ทำให้โค้ดเดิมใน `my_face_project` ทำงานช้าเกินไป

!
1. ปรับขนาดภาพเป็น 224×224 แทนที่จะเป็น 112×112:

ใน main.py (บรรทัด 66) และ prepare_known.py กำหนดขนาดภาพใบหน้าเป็น 224x224 ซึ่งมีจำนวนพิกเซล $(224^2 = 50,176)$ มากกว่าขนาดมาตรฐานของ MobileFaceNet $(112^2 = 12,544)$ ถึง 4 เท่าตัว ทำให้บอร์ดอย่าง Orange Pi / Raspberry Pi ต้องรับภาระคำนวณหนักขึ้น 400% โดยไม่จำเป็น!

!
2. การคำนวณ Cosine Similarity ซ้ำซ้อนทุกรอบ Loop:

ใน compute_similarity() มีการคำนวณ np.linalg.norm() ของเวกเตอร์ในฐานข้อมูลซ้ำใหม่ทุกๆ เฟรม แทนที่จะทำ L2 Normalization ไว้ล่วงหน้าตั้งแต่ตอนโหลด

Upgrade Solution

สคริปต์แปลงโมเดลใน `my_face_project` เป็น INT8 ทันที

สามารถนำโค้ดนี้ไปรันในโฟลเดอร์ my_face_project เพื่อสร้างโมเดล INT8 ได้เลย

convert_to_int8.py 
# convert_to_int8.py
# นำไฟล์นี้ไปวางในโฟลเดอร์ my_face_project แล้วรัน python convert_to_int8.py
import os
import onnxruntime
from onnxruntime.quantization import quantize_dynamic, QuantType

input_model = os.path.join("models", "mobilefacenet.onnx")
output_model = os.path.join("models", "mobilefacenet_int8.onnx")

print(f"[*] กำลังแปลงโมเดลจาก {input_model} -> {output_model}...")

# แปลงเป็น Dynamic INT8 Quantization
quantize_dynamic(
    model_input=input_model,
    model_output=output_model,
    weight_type=QuantType.QInt8
)

old_size = os.path.getsize(input_model) / (1024 * 1024)
new_size = os.path.getsize(output_model) / (1024 * 1024)

print(f"[✓] แปลงสำเร็จ!")
print(f"    - ขนาดเดิม (FP32): {old_size:.2f} MB")
print(f"    - ขนาดใหม่ (INT8): {new_size:.2f} MB (ลดลง {(1 - new_size/old_size)*100:.1f}%)")
